## New
- **S / M / L now sizes the story text, not just tooltips.** The size buttons in the top bar now change the dialogue, choices, speaker name and the pinyin above words, as well as tooltips. M is the same size as before, S is a little smaller and L is a quarter larger. Your saved size carries over. (#28, #31)

## Fixes
- **Pinyin no longer runs together.** With pinyin (拼) turned on, neighbouring words' pinyin used to touch, so 站在船 read as "zhànzàichuán". Words now have a small gap between them when pinyin is shown. (#28, #31)

## Testing status
- The text size and pinyin spacing changes have been confirmed on desktop and on a phone. (#28)
- Levels 1–3 have been checked more closely for visuals. The final levels will get the same check as they become available. (#20)
- Native speaker review of the dialogue is still pending. (#4)
